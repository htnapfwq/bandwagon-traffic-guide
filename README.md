## 搬瓦工流量是怎么算的？先搞清楚这个再说

搬瓦工的流量计算规则是双向计费。什么意思？简单说就是：**上行 + 下行 = 你的总消耗**。

你从服务器下载了 1GB 文件，消耗 1GB。用户通过你的 VPS 访问了某个网站，VPS 给用户回传了 500MB，这也计入流量。这点和国内一些只算下载的服务商不同，搬瓦工两边都算进去的。

实际用下来，跑代理的朋友通常消耗会比预期高——因为你发出去的请求（请求头、连接包）加上返回的数据，全部算钱。视频流媒体、大文件传输是最能吃流量的场景；纯建站、发邮件这类对流量的消耗则小得多。

还有一个细节很多人不知道：**迁移机房也会消耗流量**。在 KiwiVM 后台操作机房迁移时，迁移数据本身会计入当月使用量。如果你月底流量快满了，就别折腾迁移了。

## 搬瓦工流量怎么查看？三步搞定

流量使用情况在 KiwiVM 控制面板里直接看，不用另找工具。

1. **登录账号**：进入搬瓦工账号后台（Client Area），点击"Services"→"My Services"，列出你的所有 VPS 实例
2. **打开 KiwiVM**：找到对应的实例，点"KiwiVM Control Panel"进入控制面板
3. **查看 Bandwidth usage**：首页右侧的"Bandwidth usage"栏会显示已用流量 / 总流量，以及下次重置日期

那个重置日期很重要。搬瓦工的流量不是按自然月（每月 1 号）重置的，而是按**购买日期**的月周期来走。你 5 月 18 号买的，以后每个月 18 号流量归零重置。中美时区有差，有时候会晚一天，别急。

搬瓦工还内置了邮件提醒功能。流量用到 80%、90%、100% 时，系统会自动发邮件通知你。不需要额外设置，只要注册邮箱没填错，通知就会来。

## 流量用完了会怎样？超了要扣钱吗？

不扣额外的钱。这是搬瓦工值得说的一点：流量用超了**不会额外收费**，但 VPS 会被暂停，停到下个计费周期流量重置为止。

暂停期间服务器不可访问，但数据不会丢失，也不会被删除。等流量重置当天，自动恢复。

没有提供"单独购买额外流量"的选项。流量不够用的话，只能等下个周期，或者考虑升级到更高配的套餐。

## 一个特殊规则：切换到 CN2 机房，流量会变成三分之一

这个坑踩过的人不少，写一下。

如果你买的是 Basic VPS（原来叫 KVM 套餐），然后在 KiwiVM 后台迁移到 DC3 CN2 机房，流量会变为套餐标注值的三分之一。比如套餐写的是 1TB/月，迁过去之后实际可用只有 333GB。

买的是 E-Commerce（CN2 GIA-E）套餐的话，不管你怎么迁移机房，流量都保持原值不变。所以如果你需要频繁切机房测速，选 E-Commerce 套餐更省心。

## 怎么省流量？几个实用思路

不是每个人都需要升套餐，很多时候流量不够是因为用法问题。

**关掉用不到的服务**。VPS 装了软件没用但还在跑，一直在产生心跳包、日志同步流量——小，但时间长了也积累不少。

**压缩传输**。如果你在 VPS 上建站，开启 Gzip/Brotli 压缩，同样的内容传出去的体积小很多。

**选对机房**。物理距离近的机房，延迟低，重传少，浪费的流量也少。香港、日本机房对国内用户友好，E-Commerce 套餐里都可以切换。

**搬文件不走 VPS**。如果只是需要存储或分发文件，不要让文件流量绕道 VPS，直接走对象存储或 CDN 会省很多。

**看流量分布**。KiwiVM 里的 Bandwidth usage 只显示总量，如果你怀疑有异常消耗（比如被扫端口、遭受攻击），可以装 vnstat 之类的工具细看每小时的流量分布，找出问题来源。

## 常见问题快答

**Q：搬瓦工流量是一年总共那么多，还是每个月都有？**

每个月都有，按月重置。套餐写的 1TB/月，就是每个月有 1TB，用完的部分不累积到下个月，上个月剩的也不留到下个月。

**Q：流量用超了，会不会自动扣费或欠款？**

不会。搬瓦工是停机不扣钱，等流量重置恢复。不会有意外账单。

**Q：搬瓦工流量怎么用最多、最划算？**

流量最高效的用法是作为中转节点（建站、代理等）。消耗最大的是视频流媒体和文件传输。如果流量经常不够用，E-Commerce 套餐流量不打折，比 Basic VPS 的实际可用流量更稳。

**Q：KVM 套餐迁到 CN2 机房后流量变少了，是 bug 吗？**

不是 bug，是设计规则。Basic VPS 用 CN2 机房时流量折算为三分之一。想避免这个，买 E-Commerce 套餐或者不迁 CN2 机房。

**Q：流量重置日期能不能改？**

不能手动改，重置日期是购买日期决定的，固定的。
